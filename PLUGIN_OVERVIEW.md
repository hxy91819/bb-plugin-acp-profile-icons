See recognizable Amp and Devin brand marks when choosing models and viewing provider controls in BB.

## What you get

- A cream Amp wordmark on a dark green rounded tile for `acp-amp`.
- A white Devin mark on a dark rounded tile for `acp-devin`.
- Bundled SVG graphics that work without downloading remote images.

## How it works

The plugin uses BB's provider-icon extension. It changes presentation only: provider authentication, model selection, and agent execution stay with the configured ACP provider. Disabling the plugin restores BB's default icons.

A scoped stylesheet also colors matching logo masks in the BB 0.42 Provider Usage panel.

## Requirements

BB 0.42 or newer, Plugin SDK 0.4.47 or newer, and an existing Amp or Devin ACP provider. There are no plugin settings or additional external services.
