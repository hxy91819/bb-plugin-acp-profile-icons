See recognizable brand marks when choosing models and viewing provider controls in BB.

## What you get

- Monochrome marks for `acp-amp`, `acp-devin`, `acp-codexl`, `acp-kiro`, `acp-agy`, `acp-copilot`, and `acp-codebuddy`.
- BB's existing DeepSeek Harness mark for `acp-dsh`, in the same theme-aware style.
- Bundled SVG graphics that work without downloading remote images.

## How it works

The plugin uses BB's provider-icon extension. It changes presentation only: provider authentication, model selection, and agent execution stay with the configured ACP provider. Disabling the plugin restores BB's default icons.

A scoped stylesheet also supplies matching monochrome logo masks in the BB 0.42 Provider Usage panel.

## Requirements

BB 0.42 or newer, Plugin SDK 0.4.47 or newer, and an existing matching ACP provider. There are no plugin settings or additional external services.
